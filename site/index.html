I don’t code

A free GitHub account is required to submit work. You can read tasks before signing up. No terminal, installation, fork or pull request is required for research, writing or feedback.

  1. Choose a task and read its requirements, estimated effort and comments.
  2. Share your sources, drafted text or test findings in the issue’s comment box.
  3. A maintainer reviews your submission, asks any questions and can prepare repository changes with credit.

Start with public information research, writing or keyboard testing.

I’m a developer

Inspect the existing work before starting another feature. We need independent review of JavaScript, data validation, accessibility, GitHub Actions and recovery procedures.

  1. Read the task or PR and its acceptance criteria. Coordinate in its comments.
  2. Review or change the relevant code, run the checks, and submit a focused PR.
  3. An authorized code owner reviews technical changes. Staff acceptance and actual use are separate checks for organization work.

Website code: site/ · Tests: tests/ · CI results

Founder-authored PRs need another authorized reviewer. A trial review grants no repository access; reviewers may request changes or reject unsafe work.

Request technical help

Food banks, pantries and food rescue organizations can suggest one defined problem. Agreed humanitarian assistance is free. A request does not guarantee a volunteer, a delivery date or ongoing support.

A free GitHub account is required; the request is public. Share official URLs and public information only. Exclude beneficiary identities, aid applications, donor records, private correspondence and confidential operational data.

Suggest an organization request

Before work is represented as authorized

  1. The founder approves any outreach, and the organization’s identity and representative are checked.
  2. The organization agrees on the task, acceptance test, data boundaries and permission to publish.
  3. A willing contributor and qualified reviewer agree to a manageable scope.
  4. Technical review, staff acceptance, confirmed use and any outcome are recorded separately.
