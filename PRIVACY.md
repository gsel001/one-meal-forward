# Privacy

OneMealForward does not collect aid applications, personal profiles, precise locations, beneficiary stories, payment details, analytics, or tracking identifiers. The website uses no cookies, local storage, embedded third-party media, or third-party fonts. Filters run in your browser and are not sent to an application backend.

GitHub Pages hosts the site and may process technical request information, such as IP addresses, under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). GitHub Issues and Discussions are external public services governed by GitHub policies. Contributions, usernames, and submission content are public and may persist in history, forks, notifications, or caches. Do not include phone numbers, home addresses, immigration status, medical details, identities of people seeking food, or personal contact details. Organizations should use official public channels only.

Mission records contain public organization/task information, source links, review dates, and expiry. Keep only what is necessary; remove withdrawn or obsolete listings from the next release. Historical repository versions may remain public. We do not sell data or accept private beneficiary records.

For accidental exposure, report via GitHub's private reporting tools and the maintainer's published profile contact if available. Do not repeat sensitive details publicly. Maintainers will remove current content and request GitHub assistance where appropriate, but cannot guarantee removal from copies or third-party retention.

This policy changes through the public governance process. Last updated: 2026-11-18.
