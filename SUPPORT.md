# Support

Ask how-to questions in [Discussions](https://github.com/gsel001/one-meal-forward/discussions). Report reproducible website problems using the bug issue form, with browser, steps, and expected behavior. Never include personal data or secret tokens. Volunteer maintainers cannot promise response times.

Organization requests use the mission form and require review. This project cannot arrange emergency meals, verify a person's eligibility for aid, or promise a volunteer placement. If seeking food assistance, contact local public services or an established local relief organization directly through its official channel. We do not currently maintain a verified local assistance directory.

Report security issues privately using SECURITY.md; conduct issues follow CODE_OF_CONDUCT.md.
