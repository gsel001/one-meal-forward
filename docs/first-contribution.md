# Your first contribution in less than 10 minutes

You need a free GitHub account and a browser. You do not need a terminal or coding experience. Ten minutes is a suggested starting session; review and merging happen later.

1. **Minute 0–2:** Open [beginner tasks](https://github.com/gsel001/one-meal-forward/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). Choose a writing or manual review task. Read its checklist and any existing comments.
2. **Minute 2–3:** Comment that you would like to help. Ask a specific question if needed. You may start a small proposal without waiting for assignment.
3. **Minute 3–7:** For a small documentation improvement, open the linked file in the repository and choose the pencil/edit action. GitHub will guide you to fork the repository if you cannot edit directly. Make one clear improvement. For research, put public source URLs and check dates in a Markdown file; never include beneficiary data.
4. **Minute 7–9:** Preview your change. Choose **Commit changes**, create a branch on your fork, and write a short description of the actual change.
5. **Minute 9–10:** Choose **Propose changes** and **Create pull request**. Explain why the change helps, add `Closes #NUMBER` for the task you completed, and submit. GitHub's wording may vary; ask in the issue if you get stuck.

A maintainer will review your work and may suggest edits. That is normal collaboration. Keep replying in the same pull request. Never pay to contribute.

Prefer no file editing? Test the site using only a keyboard, then share reproduction steps in an accessibility task. Or suggest a documentation correction in an issue. Do not paste sensitive information or private screenshots.
